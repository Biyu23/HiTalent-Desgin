# HiTalent Design

HiTalent Design 是一套基于 Ant Design 的高级业务组件库，用于沉淀复杂、重复且容易出现交互分歧的业务能力。

## 它解决什么问题

Ant Design 提供了可靠的基础组件，但真实业务通常还需要窗口管理、列状态持久化、树形拖拽、海量选项和旧系统数据格式适配。HiTalent Design 将这些组合能力封装成稳定 API，让产品团队把时间用于业务本身，而不是反复拼装基础交互。

## 设计目标

- **面向真实工作流**：组件能力来自常见业务任务，而不是孤立的视觉效果。
- **保留原生能力**：在增强交互的同时继续兼容 Ant Design 的核心 API。
- **类型安全**：为复杂配置、泛型数据和实例方法提供完整 TypeScript 类型。
- **渐进采用**：可以从单个组件开始使用，无需替换现有 Ant Design 技术栈。
- **一致的国际化入口**：通过 ConfigProvider 管理语言、文字方向和组件文案覆盖。

## 组件概览

| 组件           | 适用问题                                   |
| -------------- | ------------------------------------------ |
| Button         | 异步提交、重复点击控制与禁用原因提示       |
| PopoverSelect  | 海量选项、字段映射与字符串/数组值格式      |
| Table          | 列状态、行列拖拽、树形移动与预设单元格渲染 |
| Modal          | 拖拽、缩放、最大化和多窗口最小化           |
| ConfigProvider | 样式前缀、语言包、局部文案和文字方向       |
